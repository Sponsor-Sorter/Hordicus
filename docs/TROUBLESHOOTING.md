# Hordicus — Troubleshooting

## The game will not start

1. Confirm you extracted the entire ZIP before running the game.
2. Keep the folder structure intact.
3. Run `Hordicus.exe` from the extracted folder.
4. If security software blocks the file, verify the SHA-256 against the official release before changing any security settings.
5. Report the exact error message in the official Hordicus Discord technical-support forum.

## Windows security / antivirus warning

Only trust Hordicus downloads from this official GitHub repository or links posted by the official Hordicus community.

For Public Playtest 1, the expected ZIP SHA-256 is:

```text
936d2124905f1c864cf7d9a6e14a14d1ec94b7c8d011f79814d7f6256ce5257a
```

Do not download replacement executables supplied by random users.

## Fullscreen or display problems

When reporting a display problem, include:

- Windows version
- monitor resolution
- whether you were using windowed or fullscreen mode
- what happened when entering or leaving fullscreen
- whether the game remained responsive
- screenshots/video when possible

## Save/profile problem

If settings or progress do not persist, report:

- Hordicus version
- whether the game was closed normally
- whether this was a fresh install
- whether an older Hordicus profile already existed

Do not post private Windows account information.

## Bug reports

Use the official Hordicus Discord bug-report forum and include enough detail for the issue to be reproduced.
